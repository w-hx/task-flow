# TaskFlow - Mac 菜单栏时间表应用

在 Mac 状态栏展示当前任务与剩余时间，帮助你按时间表执行每日计划。

## 运行方式

```bash
npm install
npm start
```

## 功能说明

### 状态栏
- 显示当前任务名称（超过 10 字会滚动）
- 显示剩余时间 / 总时长，如：`吃早饭 - 2:34 / 5:00`
- 无任务时显示「无任务」
- 点击图标弹出菜单：**显示 TaskFlow** | **退出**

### TaskFlow 窗口
- **左侧**：时间表列表卡片，点击编辑；加号新建；减号进入删除模式（变为 ← 返回后退出删除模式）
- **右侧**：编辑/创建表单
  - 时间表名称、内容（必填）
  - 格式：`7:30-7:35 任务内容`，每行一条
  - 保存时校验格式与时间重叠
  - 保存成功后出现 **开始运行** 按钮
  - 运行中：**停止运行** 按钮，保存按钮置灰

### 时间表格式
```
7:30-7:35 起床拿水壶出去，绑头发
7:35-7:40 刷牙、烧水、洗脸、接水烧水
7:45-7:50 吃早饭
...
```

- 最多存储 10 个时间表
- 任务时间不可重叠
